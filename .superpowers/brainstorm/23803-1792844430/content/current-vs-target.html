UI 架构重构：现状 vs 目标

app.py 从 1499 行瘦身到 ~400 行，HTML/CSS/JS 各归其位

❌ 现状：单文件巨石
app.py — 1499 行
├─ Python 路由逻辑 (~500行)
├─ _APP_CSS 内联 CSS (~125行)
├─ PAGE_BODY 内联 HTML (~25行)
├─ PAGE_SCRIPT 内联 JS (~200行)
├─ PLAN_BODY + PLAN_SCRIPT (~300行)
├─ PORTFOLIO_BODY + SCRIPT (~200行)
└─ _SHELL / _nav / _footer (~100行)
static/ — 仅 3 个小文件
common.js (64行) · dashboard.js (90行)
data-source.js (67行)
⚠️ jQuery 3.7.1 (CDN)
⚠️ Bootstrap 5.3.3 (CDN)
⚠️ Chart.js 4.4.1 (CDN)
⚠️ bootcdn.net 国内 CDN
⚠️ 无模板引擎，字符串 replace
⚠️ 无暗色模式
⚠️ 无构建工具（优点也是缺点）
✅ 目标：职责分离
app.py — ~400 行
└─ 纯 Python 路由 + API
templates/ — Jinja2 模板
base.html (shell + nav + footer)
picks.html · plan.html · portfolio.html
components/ (table, card, filter...)
static/css/ — 独立样式表
app.css (变量 + 组件 + 响应式)
static/js/ — Vanilla ES6+
api.js · table.js · filters.js
dashboard.js · plan.js · portfolio.js
static/vendor/ — 本地化依赖
bootstrap.min.css (本地)
chart.umd.min.js (本地)
✂️ jQuery 移除

重构收益

1

可维护性

改 CSS 不用翻 1499 行 Python；加新页面只需新建模板 + 路由

2

离线可用

Bootstrap/Chart.js 本地化后，无网络也能完整使用 Dashboard

3

性能

去掉 jQuery (~90KB)；CSS/JS 可被浏览器缓存；模板编译后更快

4

后续扩展基础

可转债页面、暗色模式、移动端适配都在这个基础上高效实现
