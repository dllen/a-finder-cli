# 10w 本金决策体系报告

> 生成日期：2026-10-25
> 数据区间：daily_prices 2024-10-08 ~ 2026-10-23（497 交易日，约 2 年）
> 原始数据：`docs/reports/data/10w-backtest-baseline.json`、`docs/reports/data/10w-ma-walkforward.json`
> 复现脚本：`docs/reports/10w_backtest.py`
>
> **重要声明**
> 1. 本报告基于 **paper trading（模拟）**，平台无真实资金交易记录。
> 2. 所有胜率均为**历史回测模拟结果**，**历史回测 ≠ 未来保证**。
> 3. 回测假设「选股当日收盘价买入」，实际次日开盘执行会产生约 **0.1%~0.5% 滑点损耗**，实际收益略低于报告值。
> 4. 2 年样本仅覆盖有限的市场状态（弱势市场 144/240 天），未覆盖极端行情。

## 1. 数据与方法

| 项 | 内容 |
|---|---|
| 价格数据 | `daily_prices` 148,381 行，2024-10-08 ~ 2026-10-23，300 只沪深300 |
| 选股数据 | `daily_picks` 15,219 行，277 个交易日，5 个榜单 |
| 交易计划 | `trade_plan` 313,038 行，98 个交易日 |
| 统一口径 | 滑点 0.1%、单票上限 15%、RR=2.0、ATR 止损 2x |

### 两条数据线

| 榜单 | 回测方式 | 胜率口径 |
|---|---|---|
| 均线 | `ma_backtest.py`（现成回测器） | **日胜率**：盈利天数 / 持仓天数 |
| 买入信号 / 信号策略 / 多因子 / 高胜率 | 自算（`10w_backtest.py`）：`daily_picks.buy` 价 → `daily_prices` 后续收盘价 | **笔胜率**：持仓 N 交易日后收益 > 0 的比例 |

> ⚠️ 两种胜率口径不同，不可直接横向比较。均线用日胜率衡量"每天是否赚钱"，其余用笔胜率衡量"每笔交易是否赚钱"。

### 筛选标准

**胜率 ≥ 40% 且平均收益为正**（呼应"平衡"目标：可接受胜率下最大化长期收益）。

## 2. 策略回测基线

各榜单在不同持仓周期的笔胜率与平均收益（`10w-backtest-baseline.json`）：

| 榜单 | 5 日 | 20 日 | 60 日 | 样本量(20日) |
|------|------|-------|-------|-------------|
| 均线 | 43.7% / −0.15% | 39.7% / −1.07% | 38.0% / −0.77% | 1,579 |
| **买入信号** | **48.0% / +0.33%** | **45.3% / +1.18%** | **41.9% / +0.89%** | 5,121 |
| 信号策略 | 47.2% / +0.06% | 44.1% / −0.36% | 40.6% / +0.40% | 1,625 |
| 多因子 | 47.7% / +0.10% | 45.3% / −0.14% | 40.9% / −1.78% | 5,135 |
| 高胜率 | 43.8% / −0.26% | 40.9% / −1.01% | 39.5% / +0.96% | 555 |

（格式：胜率 / 平均收益；n = 可统计样本数）

### 结论

1. **买入信号是唯一全周期达标的榜单**——5/20/60 日胜率均 ≥40%，且三档平均收益全为正。20 日（波段）表现最佳：胜率 45.3%、均收益 +1.18%。
2. **均线榜单全周期负期望**——胜率虽在 43.7%（5日），但平均收益为负，说明"赢面大但赔得更多"。**不作为选股主力**（详见第 4 节：它在组合回测中反而有效，原因见下）。
3. **高胜率榜单名不副实**——名字叫"高胜率"，实际胜率（43.8%）低于买入信号（48.0%），且样本量只有 592（others 4000+）。它是从其他榜单中二次筛选的子集，样本小、统计噪声大，**不单独使用**。
4. **信号策略与多因子在 20 日周期均为负期望**，只在 5 日周期勉强为正。两者 20 日样本量都不小（1,625 / 5,135），不是样本不足导致。
5. **5 日周期胜率普遍虚高**（43-48%）但收益接近 0——短线高胜率伴随极低赔率，扣掉滑点后大概率不划算。**本体系不采用 5 日周期**。

### 均线策略的组合回测（不同口径，重要补充）

均线在"单笔胜率"口径下为负，但在 `ma_backtest.py` 的**组合口径**（等权分散、每日调仓、含 ATR 止损）下表现优异：

| top（持仓只数） | 240日累计收益 | 超额收益 | 日胜率 | 平均仓位 | 日均入选 |
|---|---|---|---|---|---|
| 3 | **−10.50%** | −1.89% | 46.98% | 77.28% | 2.56 |
| 5 | +19.12% | +27.74% | 50.86% | 73.12% | 3.85 |
| **8** | **+31.18%** | **+39.80%** | **53.02%** | 67.86% | 5.32 |

**双窗口稳健性验证**（120 日 vs 240 日独立回测）：

| top | 120日收益 | 120日胜率 | 240日收益 | 240日胜率 |
|---|---|---|---|---|
| 3 | −8.46% | 51.33% | −10.50% | 46.98% |
| 5 | −3.69% | 53.10% | +19.12% | 50.86% |
| 8 | **+4.79%** | **53.98%** | **+31.18%** | **53.02%** |

**结论**：
- **top=3 在两个窗口都亏钱**。集中持仓在弱势市场（144/240 弱势天）被单票拖累。
- **top=8 在两个窗口都最优**，胜率 53%+，收益 +4.79% ~ +31.18%。
- 差异根源：单笔胜率口径下"每笔等额"看不出分散的价值；组合口径下"每天重新选 top N"天然自带分散与止损。

> **两个口径不矛盾**：均线策略的价值不在"单笔挑得准"，而在"每天自动选出当日相对强势的一批票并持续轮动"。用它的**组合机制**，不用它的**选股结论**。

### 2.x 独立验证：真实标注数据交叉校验

2026-10-25 跑 `evolve` 后，`pick_outcomes` 首次填充了 **16,803 条已判定记录**
（`live` 14,523 + `replay` 2,826）。这是与上表**完全独立的第二条数据流**：
标注器 `evolution/labeling.py` 用**模拟止盈止损出场**判定（前 10 交易日内
`low <= stop` 记负、`close >= target` 记胜、10 日未触发按第 10 日收盘出场），
而非上表的"持仓 N 日市价出场"。

| 榜单 | 样本 | 真实胜率 | 真实平均收益 | 对比：报告 20 日结论 |
|---|---|---|---|---|
| 多因子 | 5,335 | 45.5% | +0.04% | 45.3% / −0.14% |
| **买入信号** | 5,321 | **45.2%** | **+0.45%** | **45.3% / +1.18%** ✓ |
| 信号策略 | 1,732 | 35.8% | −0.26% | 44.1% / −0.36% |
| 均线 | 1,589 | 42.0% | −0.51% | 39.7% / −1.07% |

**验证结论**：
1. **买入信号仍是唯一「胜率 ≥45% 且平均收益为正」的榜单**——用完全独立的
   判定口径（含止盈止损）复现了第 2 章的结论。报告的核心选股结论成立。
2. **胜率数值高度吻合**（45.2% vs 45.3%），说明两条数据线的口径虽然不同，
   但对榜单相对优劣的判断一致。
3. **信号策略胜率从 44.1% 降到 35.8%**——加入止损后大量单子被止损打掉，
   说明它"看着能涨但回撤大"，更不该作主力。
4. **均线胜率从 39.7% 升到 42.0% 但收益仍为负**——止损机制有效（减少大亏），
   但选股本身不行，印证"用它的组合机制、不用它的选股结论"。

> ⚠️ 口径差异提醒：`/api/stats` 按**具体策略**（动量突破/回调买入…）聚合，
> 本报告按**榜单类型**（买入信号/多因子…）聚合。两者维度不同，不可直接对比单个数字。

## 3. 选股规则

### 结论

| 项 | 规则 |
|---|---|
| **主力榜单** | **买入信号** |
| 持仓周期 | **20 个交易日**（波段） |
| 每日买入 | 榜单 Top **8** |
| 辅助 | 信号策略（5 日短打）与多因子（5 日短打）可作补充，**不加仓** |

### 依据

- 买入信号在 5/20/60 三周期均为「胜率 ≥40% 且均值为正」，是唯一全周期达标者
- 20 日周期在胜率（45.3%）与收益（+1.18%）上同时最优
- 均线榜单不作为选股主力（单笔负期望），但其"每日选相对强势票"的机制被组合回测证明有效——通过"每日取 Top 8 买入信号"实现，而非直接用均线榜单
- 高胜率榜单样本量过小（555~592），统计噪声大，不单独使用

### 关于策略共振

**当前不采用**。信号策略与多因子在 20 日周期均值为负（−0.36% / −0.14%），共振会把负期望策略引入组合。若要引入，应限于 5 日短打且不加仓。

## 4. 仓位规则（10w = 8w 股 + 2w 债）

### 结论

| 项 | 规则 | 依据 |
|---|---|---|
| **股票总额** | **8w** | 20% 配转债降回撤 |
| **股票持仓数** | **8 只** | 双窗口验证：top=3 亏、top=8 优 |
| **单票权重** | **≤10%**（即 ≤1w/只） | 10w 本金下 15%（1.5w）单票过重，回测 top=3 已证明集中风险 |
| **实际占用** | 约 **70%~75%** | 回测平均仓位 67.86%（top=8），非满仓 |
| **现金** | 保留 **25%~30%**（约 2w~2.5w） | 弱势市场留子弹，240 天中有 144 天为弱势 |
| **转债** | **2w** | 债底保护（债底 ≥95%），下跌有限 |
| **转债持仓数** | **2~3 只**，单只 ≤1w | 10w 本金转债仓小，单票不宜超 10% |

### 依据

- **8 只 > 5 只 > 3 只**：两个独立回测窗口一致。3 只时累计收益为负（−10.50% / −8.46%），8 只时 +31.18% / +4.79%。
- **仓位不满**：top=8 时平均仓位仅 67.86%，说明信号不足的日子系统本就空仓。手动执行时**不要强行满仓**——这是回测收益的一部分来源。
- **留现金 25%~30%**：240 个交易日里 144 天被判定为弱势市场，现金是熊市生存的前提。
- **单票 ≤10%**：与 config 的 MAX_SINGLE=0.15 相比更保守。10w 本金下 15% = 1.5w，一只票的波动就能显著影响净值。

## 5. 退出规则

### 结论

| 项 | 规则 | 平台对应 |
|---|---|---|
| **止损** | **ATR × 2** 或 **−8%**，取先触发者 | `config.STOP_ATR_MULT = 2.0`，plan 的 `stop_price` |
| **止盈** | **+20%**（即 RR = 2.0） | `config.RR_TARGET = 2.0`，plan 的 `tp_price` |
| **时间止损** | 持有满 **20 个交易日**未达止盈 → 无条件了结 | 配合第 3 节的 20 日周期 |
| **移动止盈** | 浮盈 >10% 后，止损上移至成本价 | 需人工执行 |
| **组合级熔断** | 连续 **3 笔**止损 → 股票仓降至 2w 观望 | 需人工执行 |

### 依据

- 回测中 ATR 止损触发 10 次（top=8 / 240日），说明止损在震荡市中确实被用到，贡献了正超额
- **时间止损**是本体系的必要补充：笔胜率数据显示 20 日周期胜率仅 45.3%，若不止损，长期持有会把小亏拖成大亏
- **RR=2.0 的含义**：盈亏比 2:1，理论盈亏平衡胜率是 33%。实测 45.3% 有约 12 个百分点的安全垫
- **组合熔断**：连亏 3 笔是策略失效的早期信号，此时降仓比继续执行更安全

## 6. 复盘节奏

| 频率 | 动作 | 数据源 |
|---|---|---|
| **每日**（收盘后） | 看今日 plan，按第 3/4/5 章执行 | 交易计划页 `/plan` |
| **每周**（周五收盘后） | 对比实际持仓 vs 计划，检查是否越界（超 8 只 / 超单票上限 / 未设止损） | 持仓组合页 `/portfolio` |
| **每月** | 跑策略进化，看冠军池与胜率变化 | `a-finder evolve` |
| **每月** | 检查各榜单近 30 日胜率，跌破 40% 则降级该策略 | `/api/stats` |

### 调参触发条件（满足任一即调整）

1. 某策略连续 **3 笔**止损 → 该策略降级，股票仓降至 2w
2. 某策略近 30 日胜率 **跌破 40%** → 停止使用该榜单
3. 组合总回撤 **超过 15%** → 股票仓减半（8w→4w），转债仓不变
4. 单票实际亏损 **超过 8%** 未止损 → 执行纪律问题，非策略问题，先修纪律

### 数据可得性说明

平台 `/api/stats` 的胜率统计基于 `pick_outcomes`（已标注的历史选股结果）。
该表已于 2026-10-25 通过 `evolve` 首次填充（16,803 条已判定），因此**月度复盘现已可用**：

```bash
python3 stock_cli.py evolve --db hs300.db   # 增量标注 + 策略进化
# 然后看 /api/stats 或网页「每日机会」页底部的策略胜率统计
```

**注意口径**：`pick_outcomes` 用的是模拟止盈止损出场（前 10 交易日），
与本报告第 2 章的"持仓 N 日市价出场"不同。两者对榜单相对优劣的判断一致
（见 2.x 交叉验证），但绝对值不可直接混用。

后续应每个交易日或每周跑一次 `evolve`，让标注跟上最新 picks（CI workflow
已包含 `evolve` 的周五定时任务 `weekly-evolve.yml`）。
