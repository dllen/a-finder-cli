# 均线策略稳健性验证 — 设计文档

日期：2026-08-15
状态：已评审

## 目标

确认当前 +18.28% 超额不是单次切分运气，给出可信的超额区间。这是"继续优化均线策略"三阶段（稳健性验证 → 放松趋势门槛 → 搜索配额/权重）的第 1 阶段。

## 方法

在现有 174 天回测窗口上做两类验证：

1. **固定末段留出（对照基准）**：前 60% 训练、后 40% 验证（与现有 `--walk-forward` 一致）。
2. **随机连续切分 × 10**：固定随机种子，每次在 [30%, 70%] 区间随机取切分点，切分点前训练、后验证。保持时间顺序，不做 shuffle（shuffle 会泄露未来）。

每一切分：训练段用候选规则搜索 + `optimize_backtest_params` 选参，验证段独立跑，只记录验证期超额。

## 产出

新增 `--robust` 参数，打印：

| 指标 | 说明 |
|---|---|
| 固定末段验证超额 | 对照基准 |
| 随机切分验证超额 | 中位数 / 最小值 / 最大值 |
| 正超额窗口占比 | N=10 中超额 > 0 的比例 |
| 结论 | 中位数 > 0 且 ≥ 70% 窗口超额为正 → 稳健；否则判过拟合 |

## 实现边界

- 新增 `run_backtest_window`（复用现有 `run_backtest` 的 `end_shift_days` 实现窗口语义，无需截断数据）。
- 抽取 `tune_on_window` 复用现有 `candidate_config_variants` + `optimize_backtest_params`，`walk_forward_tune` 改为调用它，零重复逻辑。
- 不改任何策略/评分/数据逻辑，纯验证层。

## 明确不做

- 不放松趋势门槛（Stage 2）、不搜配额/权重（Stage 3）。
- 不扩数据、不改回测止损/regime 逻辑。
