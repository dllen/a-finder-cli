## 一、目标

基于平台现有 2 年回测数据，产出一份《10w 本金决策体系报告》，给出**选股 → 仓位（8w 股 + 2w 债）→ 退出 → 复盘**的可执行全流程 SOP。

**目标约束（用户确认）**：
- 胜率 ≥40%（平衡目标：在可接受胜率下最大化长期收益）
- 资产范围：股债 8:2（80% 沪深300 股票 + 20% 可转债，用转债债底保护降回撤）
- 持仓周期：由数据定（用回测对比日级/周级/月级）

**非目标**：
- ❌ 本次只产出报告，不改代码、不动 config.py、不做新工具
- ❌ 不声称"保证胜率"——平台是 paper trading，无真实资金战绩，诚实标注历史≠未来
- ❌ 不展开"固化"阶段（第 7 章固化清单是下一步 spec 的输入）

## 三、方案（方案 A：基于回测的全流程体系报告）

### 3.1 回测方法学

```
回测数据   : daily_prices 2 年日线（2024-10-08 ~ 2026-10-23）
回测工具   : ma_backtest.py 的 walk-forward（滚动窗口，避免过拟合）
             + optimize/search-weights（参数寻优）
统一口径   : 滑点 0.1%、单票上限 15%、RR=2.0、ATR 止损 2x、最多 8 只
待测维度   :
  ① 策略 : 均线 / 买入信号 / 信号策略 / 多因子 / 高胜率
  ② 周期 : 5 日 / 20 日 / 60 日（短线/波段/中线）
  ③ 仓位 : 3 只 / 5 只 / 8 只（集中/均衡/分散）
  ④ 股债 : 纯股票 vs 8:2 股债
筛选标准   : 胜率 ≥40% 且期望收益为正
```

**决策**：
1. **walk-forward 而非一次性全样本**——滚动窗口（前 N 天训参、后 M 天验证），避免"后视镜选参"过拟合。
2. **转债部分定性处理**——转债历史 K 线不可靠，不做精确逐笔回测；用"cb_picks 榜单 + 债底保护"的定性结论，报告诚实标注。
3. **统一口径**与 config.py 现状一致（MAX_SINGLE=0.15、RR_TARGET=2.0、STOP_ATR_MULT=2.0、MAX_POSITIONS=8）。

### 3.2 报告章节结构（7 章）

```
# 10w 本金决策体系报告（2026-10-25）

1. 数据与方法
   数据范围、回测口径、诚实声明

2. 策略回测基线
   五榜单 × 三周期 回测矩阵（胜率/期望收益/最大回撤）
   一张总表 + 每策略一段结论

3. 选股规则
   主力榜单（1-2 个）+ top N + 是否策略共振

4. 仓位规则（10w = 8w 股 + 2w 债）
   股票买几只、单票%、留现金
   转债买几只、单只上限
   3/5/8 只的胜率/回撤对比

5. 退出规则
   止损（ATR 2x 或固定%）、止盈（RR 2.0）、移动/分批止盈
   对应 plan 的 stop_price / tp_price

6. 复盘节奏
   每周看 /api/stats、每月跑 evolve、调参触发条件

7. 固化清单
   哪些规则 → config.py、哪些 → 新工具（下一步 spec 输入）
```

**决策**：
- **结论先行**——每章先给可执行结论，再给回测证据支撑
- **胜率≥40% 是硬筛选线**——低于它的策略不进主力，即使收益高
- **第 7 章是"固化"接口**——只出清单，不实现
