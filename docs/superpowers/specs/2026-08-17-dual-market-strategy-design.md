# 策略优化设计：牛市顺势 + 熊市超跌 + 减少交易

**日期**：2026-08-17
**状态**：已批准

---

## 一、目标

让策略在牛市和熊市都可以盈利，同时减少无效交易次数：

- **牛市**：顺势做多（均线突破、回踩）
- **熊市**：只抓极端超跌反弹（RSI < 20 + 底部确认）
- **震荡市**：降低频率，宁缺毋滥
- **总体**：减少 30%+ 交易次数

## 三、MarketRegimeDetector（市场状态判断）

**文件**：`market_regime.py`（新增）

### 3.1 三维度判断

| 维度 | 权重 | 指标 |
|------|------|------|
| 技术指标 | 40% | MA200方向、均线排列、波动率、ADX |
| 宽基指数 | 35% | 20日均线方向、RSI、创新高新低比 |
| 基本面 | 25% | 估值分位数、流动性 |

### 3.2 判定规则

```
综合得分 = 技术×0.4 + 指数×0.35 + 基本面×0.25

> 0.3  → 牛市 (bull)
< -0.3 → 熊市 (bear)
其他   → 震荡市 (sideways)
```

### 3.3 接口

```python
@dataclass
class MarketRegime:
    regime: str          # "bull" | "bear" | "sideways"
    confidence: float    # 0-1，判断置信度
    signals: dict        # 各维度信号详情

def detect_regime(
    index_prices: List[float],
    macro_indicators: dict,
    lookback_days: int = 60,
) -> MarketRegime:
```

## 四、SignalScorer（信号强度评分）

**文件**：`signal_rules.py`（增强）

### 4.1 评分维度

| 维度 | 分值 | 权重 |
|------|------|------|
| 指标数量 | 0-50 | 同时满足的指标数 × 10 |
| 空间距离 | 0-40 | 离关键价位越近分越高 |
| 历史胜率 | 0-30 | 相似市场状态下的历史表现 |
| 动量强度 | 0-30 | 近5日/20日涨幅 |

**总分**：0-100

### 4.2 信号分级与仓位

| 分数 | 级别 | 建议仓位 |
|------|------|----------|
| 75-100 | 强信号 | 15-20% |
| 50-74 | 中信号 | 8-12% |
| 25-49 | 弱信号 | 3-5% |
| < 25 | 不交易 | 0% |

### 4.3 仓位公式

```
仓位 = min(base_position × signal_multiplier, max_position)

- 牛市 base = 15%
- 熊市 base = 8%
- signal_multiplier = signal_score / 75 (上限1.5)
- max_position = 20%
```

## 五、AdaptiveCandidate（市场自适应选股）

**文件**：`candidate_rules.py`（增强）

### 5.1 牛市模式（bull）

沿用现有逻辑：

- 均线多头排列 + 突破/回踩/趋势信号
- momentum_20_min = 0.03
- ma10_distance_max = 0.09
- RSI < 70 才考虑（避免追高）

### 5.2 熊市模式（bear）

**严格条件，只做超跌反弹**：

| 条件 | 参数 |
|------|------|
| RSI | < 20 |
| KDJ | K < 20 或 J < 0 |
| 价格位置 | 接近 20 日低点 |
| 均线状态 | MA20 走平或向上 |
| 成交量 | > 均量 1.5x |

**全部满足才入场**，否则空仓。

### 5.3 震荡市模式（sideways）

**降低频率**：

| 调整项 | 参数 |
|--------|------|
| 突破确认 | 需要 2% 涨幅 |
| 回踩精度 | 只做 MA10 ±1% |
| 最大持仓 | 10 个交易日 |
| 止损 | -5% |

## 六、PositionManager（仓位与止损）

**文件**：`risk_manager.py`（新增）

### 6.1 三重止损

#### 固定止损

| 市场 | 止损 |
|------|------|
| 牛市 | -8% |
| 熊市 | -5% |
| 震荡市 | -5% |

#### 移动止损（跟踪盈利）

```
盈利 5%  → 保本
盈利 10% → 锁定盈利 5%
盈利 15% → 锁定盈利 10%
最高锁定盈利 15%
```

#### 时间止损

| 市场 | 最大持仓 |
|------|----------|
| 牛市 | 30 天 |
| 熊市 | 10 天 |
| 震荡市 | 10 天 |

### 6.2 止盈逻辑

| 市场 | 止盈条件 |
|------|----------|
| 牛市 | MA20 跌破 或 固定止盈 20% |
| 熊市 | 反弹 10% 或 RSI > 60 |
| 震荡市 | 固定止盈 8% |

## 七、回测验证（样本外测试）

**文件**：`ma_backtest.py`（增强）

### 7.1 滚动窗口验证

```
训练集：T-310 ~ T-60（1年）
测试集：T-60 ~ T（2个月）
滚动步长：20 个交易日
```

### 7.2 评估指标

| 指标 | 合格线 |
|------|--------|
| 年化收益率 | > 8% |
| 夏普比率 | > 0.8 |
| 最大回撤 | < 20% |
| 胜率 | > 50% |
| 交易次数 | 减少 30%+ |

### 7.3 过拟合检测

```
训练集收益 - 测试集收益 > 10% → 过拟合警告
测试集夏普比率 < 0.5 → 策略失效
```
